# Codly CLI 优化 TODO

基于当前项目源码，以及 Claude Code、Codex CLI、Gemini CLI、OpenCode 的官方文档整理。
继续沿用 Java 17 + JLine；会话、配置、工具与存储能力下沉到共享核心，由 CLI 和 Swing 入口复用。

## 已完成的问题修复

- [x] `/compact` 通过共享会话服务压缩，包含首条用户消息和消息角色，不再把首条用户消息当成系统提示词；使用不带工具的补全请求。总结失败或为空时保留原上下文，原始日志不覆盖。
- [x] `/clear` 通过共享会话生命周期新建对话，重置自动命名、异步标题代次及临时授权，保留工作区、模型、思考深度、批准策略和激活 Skills。
- [x] 进度动画停止后终止线程，避免每轮新增一个长期等待的线程；重复停止安全，停止返回后不再输出动画。
- [x] Token 用量采用模型返回的 usage，多次工具往返累计统计；回调次数只作为流式分块计数。没有 usage 时不估算 token 或 token/s，保留最近一轮完整统计。
